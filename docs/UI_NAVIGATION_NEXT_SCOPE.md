## 已发现的接线缺口

- 部分游戏布局画有「菜单」「记录」，但当前控制器尚未给这些常驻位置绑定完整导航。F5/F6/F7 快捷键不等于鼠标入口已接通。
- 已批准 UI29 是系统菜单，包含继续、存档、本机备份、阅读、玩法说明、反馈及返回主菜单确认。
- UI21 是玩法说明，不是系统菜单。UI27 是家人近况；UI28 是记录册（家用/动物/远行），不能把「记录」误连成仅照片记录。
- UI20 四页目前可从正常结局入口或 F7 查看。它们不代替整个记录册。
- 主菜单玩法说明、反馈仍须完成真实入口与返回路径。不可把静态设计文字或禁用占位当成功能完成。

## 下一批顺序

1. 先核对旧来源的菜单、继续、返回及未保存会话语义。
2. 按批准 UI29 接系统菜单及已有保存/阅读入口；按 UI25 接返回确认，保留取消路径。
3. 补 UI21、UI27、UI28 及记录入口。记录展示只读，不推进日期、随机数、资源或知识。
4. 用原生控件事件检查返回栈、禁用状态、重复打开、未保存进度保护。与已有流程回归分开列证据。
5. 在可用图形环境中用真实鼠标与真实窗口截图验收，才可判断 UI 1:1 实装。
